# ✨ Found Courses

[Português](#português) | [English](#english)

## Português

Um script em PHP que busca e exibe cursos de Back-end disponíveis no catálogo público da Alura, com uma cara mais bonita, organizada e fácil de usar.

### O que ele faz

- busca os cursos públicos da Alura;
- filtra por títulos relacionados a PHP;
- organiza os resultados em ordem alfabética;
- mostra uma lista amigável e legível no terminal.

### Como usar

Requisitos: PHP 8.1+ e Composer.

```bash
composer install
php courses.php
```

### Resultado esperado

O script imprime os cursos em ordem alfabética e exibe o total final de itens encontrados.

## English

A cute little PHP script that searches and lists Back-end courses available in Alura's public catalog, keeping things neat, readable, and a bit more stylish.

### What it does

- fetches Alura public course data;
- filters titles related to PHP;
- sorts results alphabetically;
- prints a clean and readable list in the terminal.

### How to run

Requirements: PHP 8.1+ and Composer.

```bash
composer install
php courses.php
```

### Expected output

The script prints the courses in alphabetical order and shows the final total of matching items.
